# Commons Vector Protocol — commons-vector-v1

## The New Kybalion — Hermetic Principles for the Digital Age

Commons Vector Protocol (CVP) is an IPFS-native provenance framework for representing digital content, local context, authenticated records, and historical references as verifiable instruments.

The project combines three distinct layers:

1. CVP — the technical protocol
2. TRUST-ORDBOK — the semantic dictionary
3. The New Kybalion — an artistic and philosophical framework

These layers are intentionally distinguished so that technical claims, historical research, governance structures, and artistic expression can be evaluated independently.

## Context

The protocol uses a local contextual model based on the gateway and folder structure.

The fundamental principle is:

"The folder is context."

Objects contained within a defined gateway/folder context inherit that local contextual scope.

The contextual coordinates are:

- tri_vector: 1a0de0b-f30c
- spatial_vector: 7e34-88a8
- rule_vector: 057e4f535abc

These coordinates describe protocol context. They do not replace the CID.

---

## Content and Context

CVP separates content from context.

CID = CONTENT

The CID identifies the content-addressed object.

GATEWAY + FOLDER = LOCAL CONTEXT

The gateway/folder structure establishes the local contextual space in which an object is interpreted and organized.

The Tri-Vector belongs to that contextual structure.

---

## Instrument

An instrument is a verifiable protocol record that references content and its provenance.

Example:

```
{
  "instrument": "001",
  "trust": "commons-vector-v1",
  "dictionary": "TRUST-ORDBOK-v2.0-IPFS",
  "cid": "bafk...",
  "previous": "000"
}
```

A subsequent instrument may reference the preceding instrument, creating a provenance chain.

---

## Minimal Objects

The minimal conceptual model consists of four primitive objects:

- Dictionary
- Instrument
- CID
- Provenance

Other protocol structures can be derived from these primitives.

---

## Living Archive

The Living Archive represents the historical relationship between observations, records, content identifiers, instruments, and provenance.

Observation → Record → CID → Instrument → Provenance → Archive

The archive preserves the history of records without requiring the underlying content to be stored directly inside the Git repository.

---

## Verification

CVP can provide mechanisms for verifying:

- content identifiers
- document integrity
- signatures
- references
- sequence
- provenance
- dictionary versions
- historical relationships

The protocol itself does not establish:

- ownership
- statutory title
- government authority
- court jurisdiction
- land registration
- patent rights
- banking authority

Those matters depend on external legal, contractual, institutional, or governmental systems.

---

## The New Kybalion

The New Kybalion provides the artistic and philosophical framework surrounding the protocol.

Conceptual progression:

Mind → Definition → Record → CID → Instrument → Provenance → Memory → Archive

The artistic framework and the technical protocol are related but are not asserted to be the same category of evidence.

## Research

The repository may contain historical, scientific, technical, and philosophical research.

Research claims should be distinguished from:

- primary-source evidence
- secondary-source interpretation
- protocol definitions
- artistic expression
- governance proposals

Contradictory sources should remain visible rather than being silently removed.
